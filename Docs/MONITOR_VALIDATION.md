Intel Iris Plus, 1280×800, 시드 42, 20프레임 워밍업 뒤 120프레임 마을 벤치마크. 두 실행 모두 GL 오류·프로파일 로그 유실 없음. 켜짐 실행의 전송 실패·미전송 교체 카운터 0.

## 별도 Chrome 창 실행 수정 (2026-10-12)

- 실행기는 Chrome 설치 위치를 자동 탐색하거나 `-ChromePath`를 사용하고 `--new-window`로 대시보드를 연다. 기본 브라우저 설정은 변경하지 않는다.
- 기존 Chrome 창 두 개와 구분되는 `GSE 월드 모니터 - Chrome` 창 생성 확인. 최소화된 창을 자동 활성화하는 도구는 실패하여 새 Chrome 창의 화면 캡처는 수행하지 못했다. 동일 로컬 HTML의 내용·필터 검증은 별도 브라우저 테스트 탭에서 수행했다.
- PowerShell 구문 검사, 존재하지 않는 명시적 Chrome 경로의 조기 실패, `-NoBrowser`의 Chrome 탐색 생략과 기존 서버 재사용 검사 통과.
- Windows에서 동일 포트에 수신기가 중복 바인딩되는 문제를 방지했다. 수신기 단위/HTTP 검사에 중복 리스너 검사를 추가하여 총 4개 통과.
- 실제 게임 JSON 10개: 주민 36명, 마을 몹 18마리, 야생동물 15마리, 네 가지 사건 단계, 사냥터 전환 확인.
- 지연 시작한 서버는 순번 6, 재시작한 서버는 순번 10을 수신하여 재연결 검사 통과.
- 로컬 HTML에서 36명 목록, 세라 이름 검색 1명, 정지 필터 2명(하온·세린), 게임 종료 후 오래된 관측값 표시 확인.
- 이번 변경은 실행 스크립트·Python 수신기·검사·문서에 한정되며 C++ 게임은 기존 빌드로 통합 검증했다. 산출물은 `outputs/Monitoring/ChromeWindow`에 보존했다.
