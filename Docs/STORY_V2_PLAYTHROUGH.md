# 용병 서장 · 먹고사는 일과 남겨진 색

2026-11-02. 기준 원문: [openworld_rpg_story_v2.md](openworld_rpg_story_v2.md). 사용자가 제공한 새 설정을 바탕으로 기존 GSE 실행 타깃을 수정했다. 원문의 확정 설정과 구현 편의를 위한 수치를 구분한다.

## 게임에서 바뀐 점

애도 여행자가 아닌 동전3닢을 가진 떠돌이 용병으로 시작한다. 살아 있는 푸른 여우가 어깨 높이에서 떠다니며 전투를 돕는다. 검·망토·붕대·여행 가방을 도형 모델로 표현하고 두 새 모델을 파일 캐시한다. 첫 두 의뢰는 탈색 조사와 무관한 마을의 일상 업무다.

## 조작과 동료

WASD 이동, Shift 달리기, E 대화/획득, Space 검 공격, F 여우 지원, Q 회복약, P 기록, J 수첩. 상인 대화 중1 구매, 성직자 대화 중2 치료. 수첩은 좌우/1~3으로 넘기고 J/P/E/Esc로 닫는다. 읽는 동안 시뮬레이션이 정지한다.

여우는8m 이내 충돌 시야가 트인 살아 있는 적 하나를 대상으로3초 감속·약화한다. 자동 발동 및F는 같은2.4초 재사용 대기시간을 공유한다. 약화 중 이동속도55%, 검 피해12→18이며 여우 자체의 공격 피해는0이다. 푸른 연결선과 표식으로 발동을 표시한다. 일반 징후 때는 평소처럼 동행하고, 급속 탈색이 일어난 마을 근처에서는 주인공에 바짝 붙고 꼬리 움직임이 줄어든다. 동료는 Actor로 소유·컬링·변환을 관리한다.

F3은 개발용 사건 앞당기기이며 일상 의뢰와 두 그림 기록 전에는 동작하지 않는다. Esc 휴식, R 초기화/사망 회복. F1은 기존의 별도 개발용 사냥터로 전환하며 이 서장의 필수 경로가 아니다. 진행 저장은 아직 없다.

## 일반 탈색과 급속 탈색

일반 탈색은 기존 주민이 익숙하게 감시하던 재해다. 경고 단계의 작은 북쪽 영역에서 징후를 보여 주며 감시와 집결 절차 대사가 나온다. 파수꾼과의 대화 이후 급속 확산이 시작되고8초 동안 북쪽 반경0.8→6m로 확대된다. NPC·동물·꽃·불꽃은 완전 탈색 구역에서 정지한다. 탈색된 삶을 그림이나 동료가 되돌리지는 않는다.

원문의 며칠→몇 시간 차이를 튜토리얼에서 체험하도록40초 경고/8초 확산으로 압축했다. 북쪽은 국소 사건이므로 마을 전체가 멸망했다고 표현하지 않는다. 대피와 구조·돌봄은 확산 타이머가 끝나도 진행할 수 있다. 가족을 위험 구역으로 데려가 완전 탈색시키면 부활시키지 않으며 해당 인물은 구조 불가로 처리하고 남은 생존자를 안내한다.

원문은 중후반에 인위적 가속을 밝히지만 현재 서장에서는 속도의 이상만 드러낸다. 배후 세력·방법·목적·최종 적·엔딩을 임의로 확정하지 않았다. 일반 탈색을 해제하는 마법이나 조사 사명을 도입하지 않았다.

## 수첩과 내장 그림

처음 두 페이지는 식비·풍경·장난스러운 동료에 대한 개인적인 메모다. 사건 이후 세 번째 그림을 기록하면 이전 페이지에도 주민의 행동과 사연을 덧붙인다. 그림의 이미지는 언제나 색이 남아 있던 풍경/그날 기록을 나타내며 현실을 복원하지 않는다.

내장 원화는 `Tutorial/Assets/Journal/lakeside-v2.png`, `blue-flowers-v2.png`, `stillness-v2.png`다. 기본 내장 image_gen으로 기존 수채화/연필 풍경을 보존하고 여우를 살아 있는 한색 동료로 수정했다. 세 번째는 동료를 완전 탈색된 영역 밖의 색이 남은 경계에 배치했다. 정확한 프롬프트는 `generation-v2.json`에 저장했다. 옛v1 그림은 이력으로 보존하고 실행 파일은v2 세 장만 사용한다. API 키·외부 서비스 없이 오프라인 로딩한다. 구체적인 귀·장식·벨 등의 모양은 임시 시각화다.

## 규모와 관측

마을5×소속 주민20명, 숲길 몬스터100개, 재생성·이동 소문·분위기 통계를 유지한다. 모니터 JSON v1에 선택 필드 `story.version=2`를 추가했다. 단계 키·목표·의뢰 수·의뢰 처치 수·누적 보수·보급품·구조 인원·동료 반응·재해 종류를 HTML에서 볼 수 있다. NPC 개별 행동에 따라오기/대기/집결 완료를 표시한다. 원격 마을의 지식은 여전히 순회자가 실제 이동해야 전달된다.

## 검증

`--self-test`는 실제 Actor/입력·검 공격·의뢰 보고·수첩·NPC 이동을 통해 서장을 진행하고 다음 마을의 반복 의뢰 보수까지 검사한다. 모델의 같은 상태를 복제한 테스트가 아니라 게임의 실제 상호작용 경로를 사용한다. 단위 검사로 선행 처치 제외, 물건 없는 배달 차단, 동일 인물 반복 대화 방지, 보수 중복 방지, 올바른 의뢰인, 초기화 등을 추가했다.

현재 충돌 경로332m/기본 걷기3.1m/s + 대사150초 + 전투15초 + 집결 여유15초 = 약287.1초로 필수 경로5분 목표를 검사했다. 개인별 읽기·탐험 시간과 선택 반복 의뢰는 제외한다.

`--capture-story --quiet-profile --validate-render`는 도착·전투/지원·보급품·두 일상 그림·일반 경고·급속 확산·경계하는 동료·실제 대피·정지 기록·다음 마을·반복 보고·1000×720 수첩을 실제 GL로 캡처한다. 이 가속 시나리오의 한 프레임 수치를 정상 플레이 성능으로 해석하지 않는다. 성능은 별도 벤치마크와 로그를 확인한다.

검증 결과와 성능 수치는 [STORY_V2_VALIDATION.md](STORY_V2_VALIDATION.md)를 참고하세요.
