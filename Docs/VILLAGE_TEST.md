# 스토리 마을 테스트

사용자 원문: [스토리 1차 시안](story_draft_v1.md). 원문은 변경 없이 복사했다. 아래 이름, 직업별 역할, 경로, 전투 수치와 타이밍은 **플레이 검증용 해석**이며 원문에 없는 최종 설정을 확정하지 않는다.

## 실행과 테스트 순서

`Tutorial/build.cmd`로 빌드한 `Tutorial/build/AshenShore.exe`의 기본 화면은 기존 마을이다. F1로 기존 경험치·스탯 사냥터와 전환한다. 사냥터 직접 실행은 `--level1`이며 벤치마크 기본 시나리오는 호환성을 위해 사냥터다.

1. WASD 이동, Shift 달리기, E 대화·조사·전리품 획득. 마라 → 북쪽 묘목 → 주민 3명 이상과 대화 → 호수 기록 → 마라 귀환의 짧은 동선으로 시작한다.
2. 상인과 대화 중 1: 동전 5개로 회복약 구입. 성직자와 대화 중 2: 무료 치료. Q: 회복약 사용. Space: 바라보는 쪽 근접 공격.
3. P: 북쪽 묘목 / 호숫가에서 여행 기록. 현재 기록은 텍스트와 수집 상태로 표현하며 자유 그림 편집기·그림 파일 저장 기능은 아니다.
4. F3: 일상 → 징후 → 대피 → 국소 정지로 진행. 첫 입력 후 징후 30초, 대피 60초가 지나면 자동 진행한다. F3을 다시 눌러 단계를 앞당길 수 있다.
5. 북쪽 `(0,-16)` 반경 6의 지형·인물·묘목·불꽃 정지를 확인한다. 범위 밖에서는 대피와 탐험을 계속한다. 이 작은 실험 구역은 전체 세계의 탈색 시뮬레이션 구현을 의미하지 않는다.
6. Esc 휴식, 휴식 중 Q 종료. R은 휴식/완료/정지 상태에서 테스트 초기화, 쓰러졌을 때 마을 복귀. 테스트 재시작은 서사상의 부활이 아니다. F2 후처리 비교.

사건은 원문에 따른 관찰·애도이며 원인 조사나 해결 퀘스트가 아니다. 기록이나 성직자 치료로 정지한 주민을 되살리지 않는다. 이벤트를 시작하지 않고 일상 NPC와 전투만 반복 검증할 수도 있다. 진행 상태는 메모리에 유지하며 재실행 저장은 아직 없다.

## 맵과 전투

- 기존 마을 중심과 호수 유지. 82×74 → 164×148 월드 단위: 면적 6,068 → 24,272, 정확히 4배.
- 기존 16명 + 신규 20명 = 36명. 집 5채 → 13채. 길과 숲 확장.
- 외곽 18마리의 전투용 멧돼지/망령 모델. 탈색 원인이라는 설정은 부여하지 않는다. 기존 관찰용 사슴·토끼·멧돼지 15마리 유지.
- 적은 주변 7단위에서 접근하며 서식지로부터 10단위를 벗어나면 복귀한다. 마을 중심 안전 영역에서는 추적을 중단한다. NPC를 공격하지 않는다.
- 적 체력 36, 플레이어 공격 12, 처치 경험치 20, 전리품 동전 5. 전리품은 한 번만 획득한다. 기존 사냥터 성장 시스템은 F1에서 유지한다.

## NPC 행동

모든 주민은 충돌을 피하는 격자 경로를 따라 집/일터 주변을 오가고, 대화 중에는 멈춘다. 징후가 오면 일상 이동을 끝내고 자기 자리로 돌아간다. 가족 찾기 주민은 지정된 상대의 집으로 향하며 엘린과 리오는 서로를 찾는다. 가게 정리는 징후에서 시작하고 실제 거래는 대피 단계부터 중단한다. 제빵사는 징후 중 대화하면 1회 체력 20과 회복약 1개를 준다(음식 아이템 대신 기존 회복 자원 사용).

대피 단계에서는 남아 있기 역할을 제외한 주민이 남쪽 집결지로 이동한다. 이웃 돕기는 치료·위로와 집결지 이동으로 표현하며 호위/운반 애니메이션은 없다. 남아 있는 하온이 국소 정지 영역에 걸리며 위치·애니메이션이 멈추고 무채색으로 표시된다. 가족 구조의 성공/실패 분기나 전체 지역 멸망은 아직 구현하지 않았다.

## 구조와 계측

`Village.h/.cpp`는 OpenGL·Win32와 분리된 AI/사건/상점/전투 모듈이다. 주민·적·전리품은 SceneGraph가 소유하는 Actor를 참조한다. 경로는 정적 충돌 격자와 이동 구간을 검증한 BFS이며 배치 지형이 바뀌면 월드 초기화가 필요하다. 이동 NPC끼리의 충돌은 적용하지 않는다.

`village_initialize`, `village_simulation`, `npc_pathfinding`, `village_trade` CPU 시간, 경로 요청/방문 셀/실패, 갱신 NPC·적·정지 주민 수를 JSONL로 기록한다. `village_story_phase` 이벤트 값 0/1/2/3은 일상/징후/대피/정지다. 대사나 개인정보는 로그에 남기지 않는다. `village_sketch_recorded`는 풍경/인물 기록 상태다. 자세한 공통 규칙은 `Tutorial/PROFILING.md` 참고.

## 자동 검증

- `--self-test`: 기존 게임 회귀 검사 + 36명 접근성·일상 이동·대피 도착·거래·치유·1회 보급·정지 위치/애니메이션·전투/전리품.
- `--capture --quiet-profile --validate-render`: 기본 마을·호수·대화·상인·대피·정지·작은 창 GPU 이미지.
- `--benchmark --tutorial --quiet-profile --validate-render`: 확장 마을의 동일 시드/뷰포트 성능. 짧은 벤치마크는 긴 사건 중의 최악 프레임을 대표하지 않는다.
