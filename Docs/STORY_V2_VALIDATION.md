## 실제 렌더 확인

도착·전투/지원·보급품·세 그림·일반 경고·급속 확산·경계하는 동료·가족 따라오기·다음 마을·반복 보고·작은 수첩을 캡처했다. 화면 확인 중 발견한 반복 의뢰를 가리던 옛 완료 안내, 작은 수첩 문구 겹침, 안내 전 가족 행동 문구를 수정했다. GL 오류0, 로그 유실0, 미회수 GPU 구간0이다. 가속 캡처의 단일 프레임은 일반 플레이 성능으로 해석하지 않는다.

내장 원화3장은 기본 image_gen으로 수정했다. 살아 있는 푸른 여우를 일상 장면에, 마지막 그림에는 완전 탈색 영역 밖에 두었다. 프롬프트와 파일 목록은 `Tutorial/Assets/Journal/generation-v2.json`에 있다. 옛 PNG를 덮어쓰지 않고 v2 파일로 포함했다. 런타임 API 호출이나 키가 필요하지 않다.

## 성능 관측

Intel Iris Plus Graphics / GL4.6 (27.20.100.8853),1280×800, 시드42, 후처리 켬, 모니터 끔. 각140프레임 중 워밍업20프레임을 제외한120프레임이다. 수정 전은 e5ee5cc 배포 실행 파일을 같은 PC에서 재실행했다.

세 실행의 GL 오류와 로그 유실은0이다. 새 기능의 초기 화면 Draw는 평균 3회 증가했고 마을 시뮬레이션 시간도 함께 기록했다. 이 짧은 실행의 P95는16.67ms 이내였지만 안정적인 전체 게임60FPS를 보장하지 않는다. GPU/CPU 부하 및 드라이버 상태에 따라 달라지며 관측된 차이 전체를 특정 코드의 비용으로 단정하지 않는다.

`--benchmark --tutorial --benchmark-rapid --quiet-profile --validate-render`는 별도 통제된 급속 확산 시나리오다. `companion_update`, `companion_support_select`, `companion_render_submit`, `npc_escort_update`, `desaturation_overlay_rebuild`와 작업량 카운터를 추가했다. 타이밍은 inclusive이므로 합산하지 않는다. 두 새 도형 모델은 AssetCache에 저장하며 재실행 시 캐시를 읽는다.
