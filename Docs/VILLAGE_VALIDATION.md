## 성능 관측

Intel Iris Plus / OpenGL 4.6, 1280×800, 시드 42, 20프레임 워밍업 + 120프레임, quiet 로그와 GL 오류 검사를 켠 마을 벤치마크다. 프레임 시간에는 벤치마크 전용 GPU 완료 대기가 포함된다.

| 항목 | 최종 관측 |
|---|---:|
| 평균 프레임 | 32.54 ms |
| P95 프레임 | 38.13 ms |
| 평균 Draw Call | 144.56 |
| 최대 Draw Call | 147.0 |

현재 장치의 이 측정에서는 60 FPS 예산(16.67ms)을 초과했다. 성능 목표 달성으로 판단하지 않는다. 확장된 정적 객체의 충돌 격자 재구축·씬 경계 갱신과 렌더 제출 비용은 다음 최적화 후보다. 화면 밖 그림자 처리는 공통 가시성 큐를 재사용하도록 줄였으며, 성능 효과를 확정하려면 동일 시스템 부하에서 전후 반복 측정이 필요하다.

기본 벤치마크는 2.3초 분량의 초기 일상 화면이다. 집단 대피 경로 변경의 최대 비용은 대표하지 않는다. 실제 사건은 F3으로 시작하고 `npc_pathfinding`·`npc_path_cells_visited`·`npc_path_failures` 및 `village_story_phase`를 관찰한다. 캡처의 가속 시뮬레이션 타이밍을 일반 프레임 성능으로 해석하지 않는다.

검증 산출물은 작업 공간 `outputs/VillageStory`에 실행 파일, PNG/BMP, 테스트 보고서, 캡처 로그 및 `final-benchmark` JSON 요약으로 저장했다. 실행 파일·캐시·원시 로그는 Git에 포함하지 않는다. 수동 장시간 플레이나 전체 오픈월드 스토리 완성을 의미하지 않는다.
