## 기능 검증

- 마을5곳, 각 소속 주민20명, 총100명. 전원 플레이어 접근 가능. 몬스터 슬롯100개, 야생동물15마리.

- 마을별 분위기 범위0~100, 원격 상점 유지, 국소 정지, 기존11단계 첫 장·세 그림·대화·수첩 정지·재시작·233.55초 설계 동선 검증.
- 실제 C++ 전송기 JSON10개 수신: 마을별20명/총100명, 숲길100마리, 네 사건 단계, 분위기, 원격 소문 지연과 도착 증거, 순회자 위치, F1 전환 검증.
- 모니터 단위 검사5개, 프로파일 분석기 검사2개, 기존128개 시드 사냥터 생성·성장·충돌·캐시·씬그래프 회귀 통과.

## 성능

Intel Iris Plus Graphics / OpenGL4.6 (27.20.100.8853),1280×800, 시드42, 고정dt1/60, 후처리 켬, 모니터 끔. 각140프레임에서20프레임 워밍업 제외120프레임. 타이밍은 CPU Scope inclusive이며 합산하지 않는다.

| 60초 순회 후 숲길 | 120 | 16.49 | 21.71 | 122.9 | 0.353 |

두 실행 모두 OpenGL 검증 오류0, 로그 유실0, 미회수 GPU Span0이다. P95는16.67ms 예산을 초과한다. 안정적인60FPS 달성으로 판정하지 않는다. 초기 시도에서 준비 시뮬레이션의 소문 접촉 Scope가 과도한 startup_span을 만들었으므로 실제 지식 교환 시에만 상세 Scope를 생성하고 비교 횟수는 counter로 기록했다. 표는 수정 후 최종 측정이다.

이는 짧은 정지 카메라 시나리오 측정이며 장시간 이동·대량 동시 처치·모든 사건 조합의 최악 성능을 보장하지 않는다. 원시 로그와 최종 analysis.json, 화면 캡처는 로컬 outputs/RegionalWorld에 보존한다.
