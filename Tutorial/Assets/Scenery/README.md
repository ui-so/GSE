# 배경 아트

`oldwood.png`와 `slate-cottage.png`는 달빛 항구와 옥빛 동굴 레퍼런스를 바탕으로 Codex 내장 이미지 생성 도구에서 제작했다. 그림자는 남색, 돌과 목재는 청회색, 이끼는 어두운 청록, 창문은 작은 호박색 면으로 통일한다. 지면·물가도 같은 색과 큰 면 단위의 묘사를 사용한다.

PNG는 `Tutorial/JournalAssets.rc`로 실행 파일에 내장한다. 시작할 때 WIC로 최대 384px로 축소하고 컬러·무채색을 하나의 아틀라스에 넣는다. 플레이어·NPC 스프라이트는 별도 아틀라스를 사용한다.
