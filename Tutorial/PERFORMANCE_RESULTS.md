# 성능 검증 기록 — 2026-09-28

Intel Iris Plus Graphics / Windows / 1280×800 / 후처리 켬. 시드 42, 고정 시뮬레이션 간격 1/60초, 워밍업 20프레임 + 측정 120프레임. 수치는 이 장비의 이번 실행 표본이며 전체 오픈월드·모든 장치의 성능 보장이 아니다.

이전 버전은 7efc211 기반 별도 작업 복사본이며 비교를 위해 벤치마크의 시드와 시뮬레이션 간격만 동일하게 고정했다. 기존 프레임 draw 로그는 파일로 리다이렉션했다. 최적화 버전은 --quiet-profile --validate-render로 파일 프로파일을 켰다.

| 시나리오 | 이전 제출 호출/프레임 | 최적화 draw/프레임 | 이전 처리 ms | 최적화 처리 ms |
|---|---:|---:|---:|---:|
| 첫 레벨 | 2695 | 165 | 23.1659 | 5.81904 |
| 튜토리얼 | 2260 | 116.19 (평균) | 56.3206 | 7.78899 |

공통 처리 ms는 게임 갱신 + 렌더 제출 + glFinish 완료까지이며 SwapBuffers와 루프 대기는 제외한다. 이전 버전의 glCallList는 목록당 한 번, 신규 버전은 glDrawArrays/인스턴싱당 한 번으로 계측하므로 GPU 내부 명령 수의 직접 비교는 아니다. 실제 처리 시간 개선도 함께 확인했다. 고정 Sleep(8) 제거 효과는 위 처리 시간에 포함하지 않는다.

최적화 버전의 전체 프레임 계측:

| 시나리오 | frame_ms 평균 | frame_ms P95 | 프레임 시작 간격 평균 | GPU render_total 평균 |
|---|---:|---:|---:|---:|
| 첫 레벨 | 6.0449 | 7.6129 | 6.2305 | 1.9979 |
| 튜토리얼 | 8.0136 | 9.6084 | 8.1514 | 2.7283 |

frame_ms는 표시 대기를 포함하고 프레임 마지막 직렬화는 제외한다. 시작 간격은 그 비용도 포함한다. 벤치마크는 일반 플레이와 달리 매 프레임 glFinish를 사용한다. FPS를 보장하는 값으로 해석하지 않는다.

## 마을·호숫가 그래픽 개편 검증

Intel Iris Plus Graphics, OpenGL 4.6, 1280×800에서 기준 커밋 `005de55`와 변경 후 빌드를 비교했다. 기존 고정 벤치마크에서 시나리오별 3쌍을 실행했고, 라운드마다 순서를 번갈아 바꿨다. 아래 값은 각 실행에서 워밍업 20프레임을 제외한 120프레임 통계의 중앙값이다.

| 장면 | 평균 프레임 시간 전 → 후 (ms) | P95 전 → 후 (ms) | GPU 평균 전 → 후 (ms) | 평균 드로우콜 전 → 후 |
|---|---:|---:|---:|---:|
| 마을 | 22.16 → 17.92 | 27.38 → 21.52 | 2.22 → 2.08 | 107.84 → 119.02 |
| 급변 이벤트 | 23.04 → 19.87 | 28.26 → 24.64 | 2.43 → 2.31 | 123.05 → 132.12 |
| 사냥터 | 13.95 → 13.83 | 16.60 → 16.88 | 1.99 → 2.18 | 165.00 → 167.00 |

사냥터는 반투명 나무 스프라이트의 픽셀 처리 비용이 높아 기존 인스턴싱 경로에 새 소나무 메시를 넣었다. 최종 사냥터에서는 P95가 0.28 ms, GPU 평균이 0.19 ms 증가했다. 숨김 창에서 GPU 완료를 기다리는 단일 장비의 측정이므로 수치는 같은 실험 내에서 비교한다.

Release x64 빌드, `--self-test`, `--window-test`를 통과했다. 마을과 호수, 후처리 끔, 탈색, 사냥터, 스토리 완료를 실제 OpenGL 캡처로 확인했다. 최종 캡처 3회와 벤치마크 18회에서 OpenGL 오류, 아틀라스 로드 실패 및 프로파일 로그 유실은 0건이었다.

## 지형과 건물의 투영 일치

기준 커밋 `227dc49`의 전체 집 PNG를 지형과 같은 2:1 투영으로 생성한 건물 메시로 교체했다. 기초·벽·창틀·지붕 타일은 공통 좌표계를 사용하고, 컬러·무채색 정적 VBO를 초기화 때 만든다. 투영 크기와 모델 버전을 포함하는 메시 캐시 키를 사용한다.

| 장면 | 평균 프레임 시간 전 → 후 (ms) | P95 전 → 후 (ms) | GPU 평균 전 → 후 (ms) | 평균 드로우콜 전 → 후 |
|---|---:|---:|---:|---:|

마을·급변 장면의 드로우콜은 각각 2회·3회 증가했다. GPU 평균은 마을에서 0.04 ms, 사냥터에서 0.21 ms 증가했다. 숨김 창과 GPU 완료 대기를 포함한 단일 장비의 측정이다.

Release x64 /W4 /WX 빌드와 게임·GLFW 창 검사가 통과했다. 실제로 생성된 메시의 기초, 수직선, 처마, 지붕 마루, 창틀이 지형 축과 일치하는지 검사한다. 최초 생성과 다음 실행의 디스크 캐시 적중을 확인했다. 최종 캡처 3회·벤치마크 18회에서 OpenGL 오류·캐시 검증 실패·로그 유실은 0건이었고, 캐릭터 아틀라스 출력은 기준 버전과 바이트 단위로 동일했다.
