# 성능 검증 기록 — 2026-09-28

Intel Iris Plus Graphics / Windows / 1280×800 / 후처리 켬. 시드 42, 고정 시뮬레이션 간격 1/60초, 워밍업 20프레임 + 측정 120프레임. 수치는 이 장비의 이번 실행 표본이며 전체 오픈월드·모든 장치의 성능 보장이 아니다.

이전 버전은 7efc211 기반 별도 작업 복사본이며 비교를 위해 벤치마크의 시드와 시뮬레이션 간격만 동일하게 고정했다. 기존 프레임 draw 로그는 파일로 리다이렉션했다. 최적화 버전은 --quiet-profile --validate-render로 파일 프로파일을 켰다.

| 시나리오 | 이전 제출 호출/프레임 | 최적화 draw/프레임 | 이전 처리 ms | 최적화 처리 ms |
|---|---:|---:|---:|---:|
| 첫 레벨 | 2695 | 165 | 23.1659 | 5.81904 |
| 튜토리얼 | 2260 | 116.19 (평균) | 56.3206 | 7.78899 |

공통 처리 ms는 게임 갱신 + 렌더 제출 + glFinish 완료까지이며 SwapBuffers와 루프 대기는 제외한다. 이전 버전의 glCallList는 목록당 한 번, 신규 버전은 glDrawArrays/인스턴싱당 한 번으로 계측하므로 GPU 내부 명령 수의 직접 비교는 아니다. 실제 처리 시간 개선도 함께 확인했다. 고정 Sleep(8) 제거 효과는 위 처리 시간에 포함하지 않는다.

최적화 버전의 전체 프레임 계측:

| 시나리오 | frame_ms 평균 | frame_ms P95 | 프레임 시작 간격 평균 | GPU render_total 평균 |
|---|---:|---:|---:|---:|
| 첫 레벨 | 6.0449 | 7.6129 | 6.2305 | 1.9979 |
| 튜토리얼 | 8.0136 | 9.6084 | 8.1514 | 2.7283 |

frame_ms는 표시 대기를 포함하고 프레임 마지막 직렬화는 제외한다. 시작 간격은 그 비용도 포함한다. 벤치마크는 일반 플레이와 달리 매 프레임 glFinish를 사용한다. FPS를 보장하는 값으로 해석하지 않는다.

## 검증

- MSVC C++17 /W4 /WX 빌드 통과, clang-format 및 git diff --check 통과.
- 128개 맵 연결성, 기존 전투·성장·아이템·부활, 튜토리얼 퀘스트·이동·동물 테스트 통과.
- 씬 컬링과 변환/표시 변경 무효화, 배치 삼각형 순서, 로그 JSON 형식 테스트 통과.
- 충돌 공간 격자를 원래 전체 검색 결과와 다수 좌표에서 비교하고 이동·비활성 장애물 갱신 검사.
- Python 분석기: 워밍업 제외, 지연 GPU 조인, 0 카운터 포함, 잘못된 JSON 거부 검사 통과.
- 첫 레벨·튜토리얼 실제 OpenGL 캡처 확인. 불꽃 픽셀 검사와 한글·수면·성장 화면 확인.
- 측정 세션 모두 GL 오류 0, 유실 로그 0, GPU 결과 누락 없음. 후처리/프로파일 비활성 실행도 정상 종료.

벤치마크 재실행은 tools/benchmark.ps1, 메트릭 해석은 PROFILING.md를 참고한다. 원본 JSONL과 요약은 배포 결과물 Performance 폴더에도 보존한다.
